# Card Collector Incremental — The Collector's Beginning (v0.1)

A free, offline-first fantasy card-pack incremental PWA for iPhone and desktop.

## Install on GitHub Pages
1. Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` into the **root** of your `card-collector-incremental` repository.
2. In the GitHub repository go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, `main`, `/ (root)`, then **Save**.
4. Wait for the Pages deployment, then visit `https://YOUR-USERNAME.github.io/card-collector-incremental/` in Safari.
5. Safari → Share → Add to Home Screen → Open as Web App → Add.
6. Launch while online once, then test in Airplane Mode.

## Features
- 90 named cards across three sets, six rarities, four finishes.
- 12 boosters, bulk opening, duplicate sale toggle, eight passive income generators.
- Permanent discovery Codex, blessings, Ascension, permanent upgrades, offline earnings.
- Local device saves and JSON export/import.

## Notes
- v0.1 artwork uses thematic symbols and ornate CSS frames. Handcrafted illustrations are planned for later updates.
- Progress is **local to your browser/PWA** and is not stored on GitHub. Export backups regularly.
- Offline earnings are capped at two hours per return.
- Opening large batches uses direct random draws and can take longer on older phones. Future versions can add a worker-based sampler.
- GitHub Pages hosting requires a public repository on the free plan.
